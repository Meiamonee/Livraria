📚 Livraria

Este projeto é uma aplicação de livraria desenvolvida com Node.js, HTML, CSS e JavaScript. Ele oferece funcionalidades para gerenciar livros, autores e categorias, permitindo operações como cadastro, edição e exclusão de registros.

Além disso, o sistema foi desenvolvido com uma funcionalidade especial: quando um livro entra em promoção, uma notificação é emitida informando que o livro X está em promoção. Essa notificação pode ser visualizada em tempo real via WebSocket, garantindo uma experiência interativa para o usuário.

🚀 Tecnologias Utilizadas:

    Node.js

    Express

    HTML5

    CSS3

    JavaScript

    WebSocket (para notificações em tempo real)
